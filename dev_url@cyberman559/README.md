# Dev URL Switch

Firefox WebExtension для переключения между dev- и prod-доменами одним кликом.

## Возможности

- **Переключение домена** на текущей вкладке — **левый клик** по иконке
- **Открытие переключённого домена** в новой вкладке — **средний клик** (колесо мыши) по иконке
- **Индикация** — иконка становится ярко-зелёной, когда вы находитесь на dev-домене, и приглушённой серой — в остальных случаях
- Иконка обновляется в реальном времени при переключении вкладок, обновлении страниц и смене фокуса окна

## Как это работает

Если dev-домен настроен как `dev.ru`, то:

| Текущий URL | После клика |
|---|---|
| `mail.ru` | `mail.ru.dev.ru` |
| `stg.mail.ru` | `stg.mail.ru.dev.ru` |
| `mail.ru.dev.ru` | `mail.ru` |
| `stg.mail.ru.dev.ru` | `stg.mail.ru` |

### Правило определения dev-домена

Хост считается dev-доменом, если:
1. Заканчивается на `.{devDomain}` (например `.dev.ru`)
2. Не равен самому `devDomain` (например `dev.ru` — не считается dev-доменом)
3. Перед суффиксом находится минимум **2 уровня** домена (например `mail.ru`, `stg.mail.ru`)

| Хост | Dev-домен? | Причина |
|---|---|---|
| `mail.ru.dev.ru` | да | prefix `mail.ru` — 2 уровня |
| `stg.mail.ru.dev.ru` | да | prefix `stg.mail.ru` — 3 уровня |
| `foo.dev.ru` | нет | prefix `foo` — 1 уровень |
| `dev.ru` | нет | равен самому dev-домену |
| `mail.ru` | нет | не заканчивается на `.dev.ru` |

## Настройка

1. Откройте `about:addons` → **Dev URL Switch** → **Параметры**
2. Введите dev-домен (например `dev.ru`)
3. Нажмите **Сохранить**

## Управление

| Действие | Результат |
|---|---|
| **Левый клик** по иконке | Переключение домена на текущей вкладке |
| **Средний клик** по иконке | Переключение домена в новой вкладке |

## Permissions

| Permission | Назначение |
|---|---|
| `storage` | Сохранение настроенного dev-домена |
| `tabs` | Доступ к URL активной вкладки для индикации и переключения |
| `activeTab` | Доступ к текущей вкладке |
